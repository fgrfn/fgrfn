# Hi, I'm Florian 👋

I like turning random ideas, everyday problems and *"wouldn't it be nice if..."* moments into small projects.

I'm not a software developer and I don't have a deep programming background. Most of the projects you'll find here are built with the help of LLMs such as **OpenAI Codex** and **Claude Code**.

For me, vibe coding is a way to experiment, learn how software works, and turn ideas into things I can actually use.

A lot of my projects revolve around things I'm interested in myself — **homelabs, Home Assistant, automation, ESP32s, hardware, 3D printing and other tech experiments**.

Some projects turn into useful tools.  
Some remain experiments.  
And sometimes I just build something because I want to know if it can be done.

That's basically the point. 🙂
